## BLE RC Controller v1.0.1

**English** — Fixes for phones with narrow screens, and a clearer compatibility statement.
**Español** — Correcciones para móviles con pantalla estrecha y una declaración de compatibilidad más clara.
**Português** — Correções para celulares de tela estreita e uma informação de compatibilidade mais clara.

### Fixed
- On-screen controls no longer overflow on phones around 360 dp wide (the Forward button could be cut off).
- The **Buttons** tab fits narrow screens: action titles sit above their inputs, long names are shortened, and the footer no longer fails to lay out around 320 dp.
- Regression tests added for 320, 360, 390 and 430 dp widths.

### Compatibility
- Works with **Shell Bluetooth RC cars** (the ones sold at Shell fuel stations). Verified with one model; the others appear to use the same interface. **More cars are coming.**

The apps are **not code-signed**: macOS (right-click → Open) and Windows (More info → Run anyway) warn on first launch. Verified on macOS with one car model and a DualShock 4; Android and Windows builds come from CI and are not yet tested on real hardware.
