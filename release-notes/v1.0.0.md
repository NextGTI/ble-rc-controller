## BLE RC Controller v1.0.0

First public release.

**English** — Drive Bluetooth LE toy RC cars with a gamepad (DualShock 4, DualSense, Xbox, Switch Pro and others), keyboard or on-screen buttons. Remap every button, teach unknown controllers, pick which car to drive. UI in English, Spanish and Portuguese.

**Español** — Conduce coches RC de juguete con Bluetooth LE usando un mando (DualShock 4, DualSense, Xbox, Switch Pro y otros), el teclado o botones en pantalla. Reasigna todos los botones, enseña mandos desconocidos y elige qué coche conducir. Interfaz en inglés, español y portugués.

**Português** — Pilote carrinhos RC com Bluetooth LE usando um controle (DualShock 4, DualSense, Xbox, Switch Pro e outros), teclado ou botões na tela. Remapeie todos os botões, ensine controles desconhecidos e escolha qual carro pilotar. Interface em inglês, espanhol e português.

### Downloads

| System | File |
|---|---|
| Android | `ble-rc-controller-1.0.0-android.apk` |
| macOS | `ble-rc-controller-1.0.0-macos.zip` |

The apps are **not code-signed**: macOS (right-click → Open) and Windows (More info → Run anyway) will warn on first launch. See the README.

### Status
Verified on macOS with one car model and a DualShock 4. Android and Windows builds are produced by CI and **not yet tested on real hardware** — please report what you find.
